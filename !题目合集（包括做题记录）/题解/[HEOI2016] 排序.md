# [HEOI2016/TJOI2016] 排序

## 题意

给你一个长度为 $n$ 的排列以及 $m$ 次操作，每次操作会选定一个区间进行升序或者降序排序，求最后处于位置 $q$ 的数是多少

## Solution

直接模拟排序复杂度过高，肯定无法通过本题。

既然乍一看毫无头绪，那么先考虑简单的情况。

### 关键转化：01 序列的处理

若序列只含 $0$ 和 $1$，则一次区间排序可以高效完成：

- 用线段树维护区间内 $1$ 的个数；
- 对区间 $[l,r]$ 升序排序：先统计 $cnt = \text{sum}(l,r)$，然后将 $[l, r-cnt]$ 赋值为 $0$，$[r-cnt+1, r]$ 赋值为 $1$；
- 降序排序同理：$[l, l+cnt-1]$ 赋值为 $1$，$[l+cnt, r]$ 赋值为 $0$。

这样每次操作复杂度 $O(\log n)$，总复杂度 $O(m\log n)$。

### 二分答案

由于最终只询问一个位置 $q$，我们可以二分答案 $x$（值域 $[1,n]$）：

- 构造一个 01 序列 $b_i = [a_i \ge x]$（若$a_i\ge x$ 则 $b_i$ 为 $1$，反之为 $0$）；
- 用上述方法模拟所有 $m$ 次排序；
- 检查最终 $b_q$ 是否为 $1$，若为 $0$ 说明假设错误，若为 $1$ 说明假设可能正确。

**单调性证明**：若 $x$ 可行（即最终第 $q$ 位为 $1$），说明答案 $\ge x$；若不可行，则答案 $< x$。因为随着 $x$ 增大，序列中的 $1$ 只会减少，排序后的结果在 $q$ 位上也会单调从 $1$ 变为 $0$，所以二分的单调性成立。

二分总复杂度 $O(m\log^2 n)$

## Code

```c++
#include<bits/stdc++.h>
#define int long long
#define ciallo(i,x,y,z) for(int i=x;i<=y;i+=z)
const int N = 2e6 + 10, mod = 998244353, INF = 1e18;
int n, m, q, a[N], op[N], l[N], r[N];
int sum[N], pd[N];
int read() {
	int x = 0, f = 1;
	char ch = getchar();
	while(ch < '0' || ch > '9') {
		if(ch == '-') f = -1;
		ch = getchar();
	}
	while(ch >= '0' && ch <= '9') {
		x = x * 10 + ch - '0';
		ch = getchar();
	}
	return x * f;
}
void pushup(int p) {
	sum[p] = sum[p << 1] + sum[p << 1 | 1];
}
void build(int p, int l, int r, int c) {
	pd[p] = 0;
	if(l == r) {
		if(a[l] >= c) sum[p] = 1;
		else sum[p] = 0; 
		return;
	}
	int mid = (l + r) >> 1;
	build(p << 1, l, mid, c);
	build(p << 1 | 1, mid + 1, r, c);
	pushup(p);
}
void Lazy(int p, int l, int r, int c) {//懒标记
	int t = 1;
	if(c == -1) t = 0;
	sum[p] = (r - l + 1) * t;
	pd[p] = c;
}
void pushdown(int p, int l, int r) {
	//pd = 0 -> 无懒标记
	//pd = 1 -> 区间赋值为 1
	//pd = -1 -> 区间赋值为 0
	if(!pd[p]) return;
	int mid = (l + r) >> 1;
	Lazy(p << 1, l, mid, pd[p]);
	Lazy(p << 1 | 1, mid + 1, r, pd[p]);
	pd[p] = 0;
}
void update(int p, int l, int r, int lx, int rx, int c) {
	if(lx > rx) return;
	if(rx < l || r < lx) return;
	if(lx <= l && r <= rx) {
		if(!c) Lazy(p, l, r, -1);//为了和pushdown中pd保持一致，所以这里c改成-1
		else Lazy(p, l, r, 1);
		return;
	}
	pushdown(p, l, r);
	int mid = (l + r) >> 1;
	update(p << 1, l, mid, lx, rx, c);
	update(p << 1 | 1, mid + 1, r, lx, rx, c);
	pushup(p);
}
int query(int p, int l, int r, int lx, int rx) {
	//查找 [lx, rx] 中 1 的数量
	if(rx < l || r < lx) return 0;
	if(lx <= l && r <= rx) return sum[p];
	pushdown(p, l, r);
	int ans = 0, mid = (l + r) >> 1;
	ans += query(p << 1, l, mid, lx, rx);
	ans += query(p << 1 | 1, mid + 1, r, lx, rx);
	pushup(p);
	return ans;
}
bool check(int mid) {
	build(1, 1, n, mid);//重新建树
	ciallo(i, 1, m, 1) {
		int num = query(1, 1, n, l[i], r[i]);//为 1 的数量 
		int len = r[i] - l[i] + 1;
		if(!op[i]) {
			num = len - num;//为 0 的数量 
			update(1, 1, n, l[i], l[i] + num - 1, 0);
			update(1, 1, n, l[i] + num, r[i], 1);
			//把 [l, l + num - 1] 变成 0
			//把 [l + num, r] 变成 1
		}
		else {
			update(1, 1, n, l[i], l[i] + num - 1, 1);
			update(1, 1, n, l[i] + num, r[i], 0);
			//把 [l, l + num - 1] 变成 1
			//把 [l + num, r] 变成 0s	
		}
	}
	if(query(1, 1, n, q, q) == 1) return true;//验证假设是否正确
	return false;
}
void solve() {
	n = read(), m = read();
	ciallo(i, 1, n, 1) a[i] = read();
	ciallo(i, 1, m, 1) {
		op[i] = read();
		l[i] = read();
		r[i] = read();
	} //记录操作 
	
	q = read();
	int l = 1, r = n;
	while(l < r) { 
		int mid = (l + r + 1) >> 1;
		if(check(mid)) l = mid;
		else r = mid - 1;
	}//二分查找 
	std::cout << l << '\n';
}
signed main() {
	int T = 1; 
	while(T--) solve();
	return 0;
}
```
