# Problem K

## 题意

随机生成一个长度为 $n$ 的排列，会不断进行如下操作直至排列最后变成有序排列（单调递增的排列）：

每次随机选择 $\lfloor len/2\rfloor$ 个元素进行删除，$len$ 是当前剩余的元素个数

求期望长度（对于所有排列）

## Solution

假设变成有序排列后还继续操作直至最后长度变为 $1$

那么假设操作过程中长度分别为$l_0,\ l_1...l_{t}$ 且有 $l_0=n,\ l_{t}=1$​

假设 $I_i$表示操作到长度为 $l_i$ 的时候这个排列是否为有序排列（1 代表$true$，$0$ 代表$false$）

那么假设 $l_k$ 处变成有序排列，那么显然有 $I_0=...=I_{k-1}=0$，而 $I_k=...I_t=1$​

那么用差分的思想，$l_k=1+\sum_{i=0}^{t-1}(l_i-l_{i+1})·I_i$

即 $X=l_k=1+\sum_{i=0}^{t-1}(l_i-l_{i+1})·I_i$

那么期望 $E(X)=E(1+\sum_{i=0}^{t-1}(l_i-l_{i+1})·I_i)=1+E(\sum_{i=0}^{t-1}(l_i-l_{i+1})·I_i)$

对于 $I_i=0$ 的部分对于期望贡献显然为 0

所以 $E(X)=1+\sum_{i=0}^{t-1}(l_i-l_{i+1})·P(I_i=1)$

假设 $I_i=1$，首先长度为 $l_i$ 的排列总数为 $C_n^{l_i}·l_i!$（随机选 $l_i$ 个然后随机排列）

其次，长度为 $l_i$ 的排列有序的个数为 $C_n^{l_i}$（随机选 $l_i$​ 个即可，有序排列有且仅有一种）

那么 $P(I_i=1)=1/l_i!$​

所以总期望 $E(X)=1+\sum_{i=0}^{t-1}\frac{l_i-l_{i+1}}{l_i!}$
