# 消逝的盛夏

## 题意

给你一个长度为 n 的排列，其中有若干个被标记的位置。

你的任务是通过不超过 $120$ 次询问找到被标记的最小的下标是哪一个。

## 核心思路

将每个 $a_i$ 视为一个 $L$ 维二进制向量，其中

$$
L = \lceil \log_2 n \rceil
$$

当 $n \le 1000$ 时，$L \le 10$。

一次询问一个位置集合，返回的异或和可以看作这些位置上标记向量在 $\mathbb F_2$ 下的线性组合。

如果我们将位置分成若干组，每组内对应的 $a_i$ 向量**线性无关**，那么对该组做一次询问，就能唯一还原出该组内哪些位置被标记。

原因是：设组内向量为 $v_1,\dots,v_m$，标记系数为 $x_j\in\{0,1\}$，询问得到

$$
y = \bigoplus_{j=1}^m x_j v_j
$$

由于 $v_j$ 线性无关，方程组有唯一解，所以一次询问即可确定整组的标记情况。

## 分组方法

对位置 $1\sim n$ 依次处理，维护若干组线性基。

对于当前位置 $i$，尝试将 $a_i$ 插入某个已有组的线性基：

- 若插入成功，说明该向量与该组当前基线性无关，将该位置加入该组。
- 若所有组都无法插入，则新建一组，将该向量放入新组。

每组中向量的个数不会超过 $L$，因为 $L$ 维空间中线性无关向量的数量最多为 $L$。

## 询问与解码

对每个组进行一次询问，询问该组包含的所有位置。

交互库返回该组内被标记数的异或和 $y$。

该组维护了一个线性基，并且对于每个基向量，记录它是由哪些原始向量异或得到的组合掩码。

解码时从高位向低位消元：

- 如果当前 $y$ 的某一位为 $1$，则将 $y$ 异或上该位对应的基向量，同时将组合掩码异或上对应的掩码。
- 最终得到的掩码就是该组内被标记的位置集合。

遍历所有组，找到所有被标记的位置，取最小下标即为答案。

## 询问次数分析

理论下界为

$$
\left\lceil \frac{n}{L} \right\rceil
$$

对于 $n=1000$，$L=10$，下界为 $100$ 次。

实际使用贪心分组时，由于贪心策略不一定能保证每组都被填满，因此组数会略多于理论下界。

经过测试，对于 $n=1000$ 的所有排列，贪心分组法的组数最少为 $104$。

## 时间复杂度

预处理分组复杂度为 $O(nL)$，询问次数为组数，解码复杂度同样为 $O(nL)$。

整体时间复杂度 $O(nL)$，空间复杂度 $O(n + L \times \text{组数})$​。

## Code

```c++
#include <bits/stdc++.h>
using namespace std;

struct Group {
    vector<int> basis;      // basis[bit] = 该位上的基向量，0 表示空
    vector<int> mask_basis; // 对应基向量的组合掩码
    vector<int> pos;        // 该组包含的位置编号
};

// 尝试将向量 v 插入组 g，返回是否成功
// 若成功，mask_out 保存新向量在组内的标记掩码
bool tryInsert(Group& g, int v, int& mask_out, int L) {
    int mask = 1 << g.pos.size(); // 新向量在组内的索引
    for (int bit = L - 1; bit >= 0; --bit) {
        if (!((v >> bit) & 1)) continue;
        if (g.basis[bit] == 0) {
            g.basis[bit] = v;
            g.mask_basis[bit] = mask;
            mask_out = mask;
            return true;
        } else {
            v ^= g.basis[bit];
            mask ^= g.mask_basis[bit];
        }
    }
    return false; // 线性相关，插入失败
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    // 计算二进制位数 L
    int L = 0;
    while ((1 << L) < n) ++L;
    if (L == 0) L = 1;

    vector<Group> groups;

    // 将每个位置分配到合适的组
    for (int i = 1; i <= n; ++i) {
        int v = a[i];
        bool inserted = false;

        // 尝试加入已有组
        for (auto& g : groups) {
            int mask;
            if (tryInsert(g, v, mask, L)) {
                g.pos.push_back(i);
                inserted = true;
                break;
            }
        }

        // 若所有组都放不下，新建一组
        if (!inserted) {
            Group ng;
            ng.basis.assign(L, 0);
            ng.mask_basis.assign(L, 0);
            int mask;
            tryInsert(ng, v, mask, L); // 新建组必定成功
            ng.pos.push_back(i);
            groups.push_back(ng);
        }
    }

    int ans = n + 1;

    // 对每组进行询问并解码
    for (auto& g : groups) {
        if (g.pos.empty()) continue;

        // 输出询问
        cout << "? " << g.pos.size();
        for (int p : g.pos) {
            cout << ' ' << p;
        }
        cout << endl;

        int y;
        cin >> y;

        // 解码得到该组内的标记掩码
        int mask = 0;
        for (int bit = L - 1; bit >= 0; --bit) {
            if ((y >> bit) & 1) {
                y ^= g.basis[bit];
                mask ^= g.mask_basis[bit];
            }
        }

        // 根据掩码更新答案
        for (int j = 0; j < (int)g.pos.size(); ++j) {
            if ((mask >> j) & 1) {
                ans = min(ans, g.pos[j]);
            }
        }
    }
    cout << "! " << ans << endl;

    return 0;
}
```
