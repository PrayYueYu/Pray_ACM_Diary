## 消逝的盛夏

### 题目背景

梅雨霁，暑风和。又到了洲洲幼儿园小朋友最爱的猜数字小游戏的时间了。可是懒懒的哈基峰小朋友正在呼呼大睡，你能帮帮它完成这个小游戏吗？

### 题目描述

这是一道交互题。

给定一个长度为 $n$ 的**排列** $a_1,a_2,\dots,a_n$，保证 $a$ 是 $1 \sim n$ 的一个排列。

交互库会从这个排列中选出若干个位置打上标记（保证至少有一个位置被打上标记）。

你需要找出**第一个被打上标记的位置**，即最小的下标 $i$，使得第 $i$ 个位置被标记。

你可以进行不超过 **$120$** 次询问，每次询问选择一个位置集合，交互库会返回这些位置上被打标记的数的**异或和**。

具体来说，设标记位置集合为 $S$，你询问的位置集合为 $T$，那么交互库会返回：

$$
\bigoplus_{i \in S \cap T} a_i
$$

其中 $\oplus$ 表示按位异或。若 $S \cap T = \varnothing$，那么返回值是 $0$。

交互库是**非自适应**的，也就是说被标记的位置集合 $S$ 在交互开始前就已经固定，不会根据你的询问改变。

### 交互格式

第一行一个整数 $n$（$1 \le n \le 1000$），表示排列长度。

第二行 $n$ 个整数 $a_1,a_2,\dots,a_n$，保证 $a$ 是 $1 \sim n$ 的一个排列。

之后你可以按照以下格式询问：

```in
? m t1 t2 ... tm
```

表示询问位置集合 $\{t_1,t_2,\dots,t_m\}$，其中 $1 \le m \le n$，且所有 $t_i$ 互不相同，$1 \le t_i \le n$。

每次询问后，你需要从标准输入读取一个整数 $x$，表示该集合中被标记数的异或和。

如果你找到了第一个被标记的数是哪一个，用以下格式返回你的结果：

```out
! x
```

其中 $x$ 是第一个被标记的位置下标。

每次输出之后，你需要清空缓冲区，清空输出缓冲区可以使用以下方式：

- C/C++：`fflush(stdout)`（如果您使用 `printf`），`cout.flush()` 或 `cout << endl`（如果您使用 `cout`）
- Java：`System.out.flush()`
- Pascal：`flush(output)`
- Python：`sys.stdout.flush()`

见「交互格式」。

### 输出格式

见「交互格式」。

### 输入输出样例 #1

#### 输入 #1

```
5
5 4 2 1 3

3

2
```

#### 输出 #1

```


? 3 1 4 5

? 2 2 3

! 3
```

样例解释：

交互库标记了位置 $3$ 和 $5$。  
第一次询问位置集合 $\{1,4,5\}$，，位置 $1,4$ 未被标记，位置 $5$ 的 $a_5=3$，返回 $3$。  
第二次询问位置集合 $\{2,3\}$，位置 $2$ 未标记，位置 $3$ 的 $a_3=2$，返回 $2$。  
最终输出第一个被标记的位置 $3$。
