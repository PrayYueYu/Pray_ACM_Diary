# 圈圈环礁湖

## 题目大意

有 $m=100$ 套玩具，每套有 $k=10$ 个玩具，每个玩具是一个 $n\times n(n=10)$ 的数字方阵，初始按 $1$ 到 $n^2$ 顺序排列。

Alice 对正常玩具进行了大量操作：每次等概率随机选择一个 $4\times 4$ 子块，顺时针旋转 $90^\circ$。Bob 不小心弄坏了其中一半（50 套）玩具，并重新随机填写了数字（**等概率随机排列**）。

现在给出所有玩具的最终状态，你需要输出一个长度为 $m$ 的 01 串，第 $i$ 位为 `1` 表示第 $i$ 套被 Bob 弄坏，为 `0` 表示正常。你不必全部判断正确，只要正确率不低于 $90\%$ 即视为正确。

## Solution

首先注意到：$4\times 4$ 旋转是偶置换。

对于一个排列，我们可以定义其**逆序数**的奇偶性。一次 $4\times 4$ 子块顺时针旋转 $90^\circ$，等价于将 16 个元素按特定循环移位，这个置换可以分解为若干个循环。具体来说，旋转会使位置发生变化，但可以验证该置换的符号为 **偶置换**（即逆序数奇偶性不变）。更简单的理解：旋转相当于执行了多个两两交换（实际上是一个长度为 4 的循环等），其逆序数奇偶性为偶数。

因此，无论 Alice 操作多少次，**正常玩具的数字排列始终是偶排列**（逆序数为偶数）。

而 Bob 重新随机填写的玩具，其排列是均匀随机的一个 $n^2$ 个元素的排列。随机排列的逆序数奇偶性以 $\frac{1}{2}$ 概率为奇数，$\frac{1}{2}$ 概率为偶数。

对于每一套玩具（10 个玩具）：

- 若其中存在 **至少一个奇排列**（逆序数为奇数），则这一套不可能全部由正常操作得到，一定是 Bob 破坏的，标记为 `1`；
- 若 10 个玩具 **全部都是偶排列**，则这一套很可能是正常的（存在极小的概率 Bob 随机排列恰好也都是偶排列，概率为 $\frac{1}{2}^{10}=\frac{1}{1024}$，但题目允许 90% 正确率，即使误判也无关紧要），我们标记为 `0`。

时间复杂度：$O(N^4MK)$

## Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int id, m, k, n;
    cin >> id >> m >> k >> n;   // 读入固定参数

    string ans;
    for (int s = 0; s < m; ++s) {
        bool bad = false;
        for (int t = 0; t < k; ++t) {
            int total = n * n;
            vector<int> a(total);
            for (int i = 0; i < total; ++i) cin >> a[i];

            // 计算逆序数奇偶性（异或累积）
            int f = 0;
            for (int i = 0; i < total; ++i)
                for (int j = i + 1; j < total; ++j)
                    if (a[i] > a[j]) f ^= 1;

            if (f) bad = true;   // 出现奇排列，确定是坏套
        }
        ans.push_back(bad ? '1' : '0');
    }

    cout << ans << '\n';
    return 0;
}
```
